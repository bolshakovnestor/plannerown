# Художній перекладач EN → UK

Веб-застосунок: https://bolshakovnestor.github.io/plannerown/translator/

## Як працює
1. **Перекладацький паспорт тексту** — модель читає ВЕСЬ текст і в 3 проходи складає аналіз:
   - ідіостиль автора (синтаксис, лексика, як передає думки, механізми іронії), настрій і його зміни, теми й підтекст;
   - персонажі та їхнє мовлення, імена за правописом 2019 і традицією, реалії та історичний контекст (з перевіркою фактів у вебпошуку);
   - метафори, ідіоми, алюзії зі стратегіями, правила перекладу саме цього тексту, пастки.
   За замовчуванням робота зупиняється, щоб ти переглянув і, якщо треба, виправив паспорт.
2. **Переклад** фрагментами ≈350 слів. Кожен виклик бачить увесь оригінал, паспорт (prompt caching — дешево) і два попередні перекладені фрагменти.
3. **Редактура** кожного фрагмента: точність, ідіостиль, настрій, антикальки, правопис 2019, узгодженість імен, образність. Повертає остаточний текст і JSON із рішеннями та сумнівними місцями.
4. Експорт: чистий DOCX (Times New Roman 14, інтервал 1,5), двомовний HTML/DOCX, рішення (.md), TXT.

Усе виконується на сервері: кожен крок — окремий виклик Edge Function, який сам запускає наступний. Якщо крок обірвався (ліміт часу), pg_cron щохвилини підхоплює його (`lit-translate-watchdog`), а після 2 обривів effort автоматично знижується.

## Де що лежить
- `supabase/functions/lit-translate/index.ts` — сервер (TypeScript). У Supabase задеплоєно заглушку, що імпортує бандл `server/lit-translate.js` із зафіксованого коміту через jsDelivr.
- `web/public/translator/index.html` — інтерфейс (один файл; також лежить у гілці `gh-pages` в `translator/`).
- Supabase-проєкт `nestor-planner`: таблиці `lt_projects`, `lt_config` (пароль застосунку `app_key`), секрет `ANTHROPIC_API_KEY`.

## Оновлення сервера
```
npx esbuild supabase/functions/lit-translate/index.ts --bundle --format=esm --platform=neutral --target=es2022 --external:'npm:*' --outfile=server/lit-translate.js
git commit -am "..." && git push
# потім у заглушці функції замінити хеш коміту й задеплоїти
```

## Зміна пароля
SQL у Supabase: `update lt_config set value = 'новий-пароль' where key = 'app_key';` (функція підхопить після холодного старту, до ~кількох хвилин).
